💻 ¿Tenés tu propio sitio web?

Opcional · Solo para dueños con sitio web propio (WordPress, Wix, sitio a mano)

▼

Si ya tenés tu sitio web (ejemplo: mipanaderia.com), podés pegar este código y el chatbot aparecerá automáticamente en tu sitio.

📘 ¿Cómo instalo el código?
  1. Copiá el código de arriba.
  2. Entrá al editor de tu sitio web.
  3. Pegalo justo antes de la etiqueta </body>.
  4. Guardá y publicá tu sitio.
  5. ¡Listo! El chatbot aparecerá flotando abajo a la derecha.

¿No tenés sitio web? No te preocupes — con tu link y el QR ya tenés todo lo que necesitás.
